Privacy Policy

Applies to the OAuth client Hermes CLI. Last updated: 23 September 2026.

1. What this application is

“Hermes CLI” is a personal command-line tool operated by its owner, an individual academic researcher, on her own computer. It is a single-user application: it is not distributed, not offered to the public, and it has no other users. It is registered as an OAuth client in the owner’s own Google Cloud project so that it can work with her own Google account after she grants consent.

2. Google user data accessed

After the account owner grants consent, the application can access the following data of her own account only:

  • Gmail — read messages, manage labels, and send messages on the owner’s behalf (gmail.readonly, gmail.modify, gmail.send).
  • Google Calendar — read and create calendar events.
  • Google Drive — read, create and edit files that the owner already has access to.
  • Google Docs and Sheets — read and edit the owner’s documents and spreadsheets.
  • Contacts — read-only access to the owner’s contacts.

3. How the data is used

  • All processing happens locally on the owner’s own computer. Data is sent to Google’s APIs and received from them; it is not transmitted to any other server.
  • Data is used only to carry out tasks the owner asks for — for example, reading her own correspondence, filing it locally, or adding an event to her own calendar.
  • Data is not sold, rented, shared, or transferred to any third party.
  • Data is not used for advertising, profiling, creditworthiness, or any form of automated decision-making, and is not used to train machine-learning models.
  • No analytics, telemetry, or tracking is performed by this application.

4. Storage and retention

OAuth tokens and credentials are stored only in the owner’s own local filesystem. Content the owner chooses to keep (for example, a document she downloaded, or an email she archived) stays on her own computer or in her own cloud storage under her normal file management. The application keeps no remote copy of any Google user data.

5. Revoking access

The owner can revoke this application’s access to her Google account at any time at myaccount.google.com/permissions, and can delete the locally stored tokens at any time. Once access is revoked, the application can no longer read or modify any Google data.

6. Limited Use disclosure

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
